# Objetos  
Un **objeto** es una instancia de una [[002 - Clases|clase]]. Al crear un objeto, este pertenece a una clase específica y representa una manifestación concreta de esa clase en memoria.  

Los objetos contienen:  
- **Atributos**: Que almacenan su estado o características.  
- **Métodos**: Que definen sus comportamientos o acciones.  

En términos simples, un objeto es la representación física o tangible de una clase en el programa.
