## **Operadores**
A continuación se mencionan los operadores de [[001 - ¿Qué es Java?|Java]]:

### **Operadores aritméticos**

Estos operadores realizan operaciones matemáticas entre números:

- **Suma**: `+`
- **Resta**: `-`
- **Multiplicación**: `*`
- **División**: `/`

### **Operadores relacionales**

Comparan dos valores y devuelven un valor booleano:

- **Igual**: `==`
- **Menor que**: `<`
- **Mayor que**: `>`
- **Distinto de**: `!=`
- **Asignación**: `=` (Este es un operador de asignación, no comparación).

### **Operadores lógicos**

Realizan operaciones lógicas sobre valores booleanos:

- **AND**: `&&`
- **OR**: `||`
- **NOT**: `!`
