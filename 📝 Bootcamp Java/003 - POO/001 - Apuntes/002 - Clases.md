# Clases  
Una **clase** es una estructura fundamental en la Programación Orientada a Objetos que agrupa variables y operaciones en un módulo coherente.  

Una clase puede contener:  
- **Atributos**: Representan las propiedades o características del objeto.  
- **Constructores**: Métodos especiales utilizados para inicializar un objeto.  
- **Métodos**: Operaciones o comportamientos que los objetos de la clase pueden realizar.  

En esencia, una clase es una plantilla que define la forma y el comportamiento de los objetos que se crean a partir de ella.  

## Métodos  
Un **método** es un conjunto de instrucciones definidas dentro de una clase que realiza una tarea determinada. Los métodos representan los comportamientos de un objeto y pueden interactuar con sus atributos para modificar su estado o realizar cálculos.  

## Constructores  
Un **constructor** es un método especial que se utiliza para crear e inicializar nuevos objetos de una clase.  

### Características de los constructores:  
- El nombre del constructor debe coincidir con el nombre de la clase.  
- No tienen un tipo de retorno explícito.  
- Pueden o no tener parámetros.  
- Es posible definir más de un constructor para una clase (ver sobrecarga). Solo uno se ejecutará al momento de crear el objeto.  

## Sobrecarga de un Constructor  
La **sobrecarga de constructores** permite declarar múltiples constructores en una misma clase, siempre y cuando difieran en el número y/o tipo de parámetros.  

Esto facilita la creación de objetos de diferentes maneras, adaptándose a distintos escenarios de inicialización.
