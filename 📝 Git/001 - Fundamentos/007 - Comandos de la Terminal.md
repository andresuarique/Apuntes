
## **Comandos de la Terminal**

- Limpiar consola:

```
ctrl+l o clear
```

- Navegar entre carpetas:

```
mkdir nombre_de_carpeta  # Crear una carpeta  
cd nombre_de_carpeta # Entrar en la carpeta  
cd ..# Salir de la carpeta  
```

- Ver contenido de una carpeta:

```
ls
```

- Eliminar archivos o carpetas:

```
rm archivo   # Borrar archivo  
rm -r carpeta# Borrar carpeta y su contenido  
rm -rf carpeta   # Borrar carpeta y contenido forzado  
```
