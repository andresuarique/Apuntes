# Conceptos básicos sobre repositorios en Git  

En [[002 - ¿Qué es Git?|Git]], un repositorio es un lugar donde podemos guardar y administrar diferentes archivos, junto con sus versiones.  

## Tipos de repositorios  
- **Local**: Se ejecuta de forma local en cada computadora. No se conecta con otros repositorios ni es compartido.  
- **Remoto**: Está alojado en un servidor y puede ser accedido desde cualquier computadora o lugar. Ejemplos: GitHub, GitLab, Bitbucket.  

## Crear un repositorio local  
1. Ubicarnos en la terminal en la carpeta donde queremos crear el repositorio.  
2. Ejecutar el comando:  
```

git init

```
Esto crea un repositorio local y habilita las funcionalidades de [[002 - ¿Qué es Git? |Git]].  

Los repositorios locales pueden configurarse para comunicarse con repositorios remotos.
