### Testing Manual

- **Ejecutado por testers** que simulan las acciones del usuario final, basándose en **casos de prueba**.
- Principalmente utilizado para [pruebas](001%20-%20Testing.md) **funcionales**, de **usabilidad** y **exploratorias**.
- Permite detectar fallas y reportarlas manualmente.

### Testing Automatizado

- **Ejecutado por testers con habilidades técnicas** usando herramientas para crear **scripts de prueba**.
- Permite realizar pruebas de manera **automática y repetitiva**.
- Elimina tareas rutinarias, liberando tiempo para **acciones más profundas** relacionadas con el desarrollo e implementación del software.
