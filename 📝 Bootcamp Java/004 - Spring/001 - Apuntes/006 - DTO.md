### DTO (Data Transfer Object)

- **Propósito**: Crear objetos planos (POJO) para enviar o recuperar datos del servidor en una sola invocación.
- **Independencia**: Permite crear estructuras de datos separadas del modelo de datos, lo que facilita la creación de diferentes vistas.
- **Control**: Controla el formato, nombres y tipos de datos al transmitir información, ajustándose a requisitos específicos.
- **Estabilidad**: Si el modelo de datos cambia, el cliente no se ve afectado ya que sigue recibiendo el mismo DTO.
- **Inmutabilidad**: Los DTO deben ser inmutables, es decir, sus instancias no pueden modificarse una vez definidas.
- **En Spring**: Se puede retornar un DTO directamente desde un `@RestController` y Spring lo convierte automáticamente a JSON.
