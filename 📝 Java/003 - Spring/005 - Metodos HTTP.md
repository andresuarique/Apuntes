### Métodos HTTP

| **Método** | **CRUD**       | **Utilización**                                 | **¿Soporta envío de Payload?** |
| ---------- | -------------- | ----------------------------------------------- | ------------------------------ |
| **GET**    | Read           | Consultar información al servidor.              | NO                             |
| **POST**   | Create         | Crear un nuevo registro.                        | SI                             |
| **PUT**    | Update/Replace | Actualizar completamente un registro existente. | SI                             |
| **DELETE** | Delete         | Eliminar un registro existente.                 | NO                             |
| **PATCH**  | Update/Modify  | Actualizar parcialmente un registro.            | SI                             |
