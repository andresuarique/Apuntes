# Clases Utilitarias  

Las **clases utilitarias** son clases diseñadas para agrupar un conjunto de métodos relacionados que realizan funciones comunes y reutilizables. Estas clases suelen ser ampliamente utilizadas en diversos contextos dentro de un programa.  

## Características principales  
- Generalmente contienen **métodos estáticos**, lo que permite llamarlos directamente sin necesidad de crear una instancia de la clase.  
- Agrupan funcionalidades relacionadas para facilitar su uso y organización.  
- Se utilizan frecuentemente en bibliotecas estándar y en el desarrollo de aplicaciones.  

## Ejemplo de Clase Utilitaria  
Una de las clases utilitarias más comunes en Java es `java.lang.Math`, que proporciona métodos para realizar operaciones matemáticas básicas y avanzadas.  

### Ejemplo de uso:  
```java
int resultado = Math.max(10, 20);  // Devuelve el mayor de dos números
double raiz = Math.sqrt(16);      // Calcula la raíz cuadrada de un número
```
